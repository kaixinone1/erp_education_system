## 三、模板调用机制设计
### 3.1 标准化调用接口
设计理念：模板是独立的服务，提供标准化接口

```
# 模板调用接口
class TemplateService:
    """
    模板服务接口
    所有模块通过这个接口调用模板
    """
    
    def get_template_config(self, template_id):
        """获取模板配置"""
        pass
    
    def render_form(self, template_id, data=None):
        """渲染表单"""
        pass
    
    def validate_data(self, template_id, data):
        """验证数据"""
        pass
    
    def save_data(self, template_id, data):
        """保存数据"""
        pass
    
    def export_data(self, template_id, data):
        """导出数据"""
        pass
```
### 3.2 模块调用示例
人事管理模块调用模板：

```
// 人事管理模块
import { TemplateService } from '@/services/
template'

// 调用教师基础信息模板
async function showTeacherInfo() {
  // 1. 获取模板配置
  const template = await TemplateService.
  getTemplateConfig('teacher_basic_info')
  
  // 2. 渲染表单
  const formData = await TemplateService.
  renderForm('teacher_basic_info')
  
  // 3. 显示表单
  showDialog({
    title: template.chinese_name,
    content: formData
  })
}
```
退休管理模块调用模板：

```
// 退休管理模块
import { TemplateService } from '@/services/
template'

// 调用退休呈报表模板
async function showRetirementReport() {
  // 1. 获取模板配置
  const template = await TemplateService.
  getTemplateConfig('retirement_report')
  
  // 2. 渲染表单（预填数据）
  const formData = await TemplateService.
  renderForm('retirement_report', {
    teacher_name: '张三',
    id_card: '123456789012345678'
  })
  
  // 3. 显示表单
  showDialog({
    title: template.chinese_name,
    content: formData
  })
}
```

```

    v-model="menuList"

    true }"
    :animation="200"
    @end="onDragEnd"
  >
    <template #item="{ element }">
      <div class="menu-item">
        <span class="drag-handle">≡</span>
```

## 五、智能化、自动化设计
### 5.1 智能数据源配置
设计理念：用户在网页上的操作自动生成配置

示例：用户配置数据源

```
用户操作：
1. 选择数据表：teacher_basic_info
2. 选择字段：姓名、身份证、性别
3. 设置筛选条件：任职状态 = '在职'
4. 设置统计方式：计数

系统自动生成：
{
  "data_source": {
    "table": "teacher_basic_info",
    "fields": ["姓名", "身份证", "性别"],
    "filter": {
      "任职状态": "在职"
    },
    "aggregation": {
      "type": "count",
      "field": null
    }
  }
}
```
### 5.2 自动化统计配置
设计理念：根据用户选择自动生成统计逻辑

示例：用户配置统计

```
用户操作：
1. 选择统计类型：按单位统计
2. 选择统计字段：任职状态
3. 选择统计值：在职人数

系统自动生成：
{
  "statistics": {
    "group_by": "单位",
    "count_field": "任职状态",
    "count_condition": "在职",
    "result_field": "在职人数"
  }
}
```
### 5.3 智能模板推荐
设计理念：根据用户操作推荐合适的模板

```
用户场景：
- 用户在"人事管理"模块
- 需要填报教师信息

系统推荐：
- 教师基础信息表
- 教师学历记录表
- 教师职称信息表

推荐理由：
- 这些模板在人事管理模块使用频率最高
- 与当前业务场景匹配
```
