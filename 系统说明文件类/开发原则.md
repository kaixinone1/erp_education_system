# 开发原则

**制定日期：2026-05-05**
**严格遵守，绝不违反**

---

## 一、绝对禁止私自创建

### 1. 禁止私自创建表
- **绝对禁止**使用 `CREATE TABLE` 创建新表
- **绝对禁止**创建任何新的数据库表
- 只能使用用户已经创建好的现有表

### 2. 禁止私自创建菜单
- **绝对禁止**创建新的菜单项
- **绝对禁止**修改现有菜单结构
- 只能使用用户已经创建好的菜单

### 3. 禁止私自创建模块
- **绝对禁止**创建新的功能模块
- **绝对禁止**创建新的系统模块
- 只能使用用户已经创建好的模块

### 4. 禁止私自创建字段
- **绝对禁止**在现有表中添加新字段
- **绝对禁止**使用 `ALTER TABLE ADD COLUMN`
- 只能使用现有表的现有字段

### 5. 禁止私自创建数据
- **绝对禁止**写入测试数据
- **绝对禁止**写入示例数据
- **绝对禁止**使用 `INSERT` 写入硬编码数据

---

## 二、绝对禁止硬编码

### 1. 禁止硬编码任何数据
- 包括默认值、测试数据、示例数据
- 包括字符串、数字、布尔值等任何类型的数据

### 2. 禁止硬编码任何字段值
- 如 `'退休原因': '正常退休'`
- 如 `'岗位': '教学岗位'`
- 如 `'职务': '教师'`

### 3. 禁止硬编码任何数字
- 如仪表盘统计数字 `23`、`5`、`18`
- 如分页大小、默认值等

### 4. 禁止硬编码任何字符串
- 如状态值 `'pending'`、`'completed'`
- 如类型值、分类值等

---

## 三、绝对禁止私自修改用户要求

### 1. 禁止私自修改用户的指示
- **绝对禁止**改变用户的原意
- **绝对禁止**添加用户没有要求的功能
- **绝对禁止**删除用户要求保留的内容

### 2. 禁止私自解释用户要求
- 必须按照用户的字面意思执行
- 有疑问时必须询问，不能自行判断

---

## 四、正确做法

### 1. 从数据库查询真实数据
- 使用 `SELECT` 查询现有表
- 使用现有字段，不添加新字段

### 2. 如果没有数据，保持为空
- 使用 `None` 或空字符串 `''`
- 绝不使用默认值填充

### 3. 如果数据不存在，报错或提示用户
- 不假设数据存在
- 不自动创建数据

### 4. 如果需要添加任何东西，必须询问用户
- 停止工作
- 向用户说明需求
- 等待用户明确许可

---

## 五、违反后果

如果发现自己即将违反任何规定，必须：
1. **立即停止**
2. **询问用户如何处理**
3. **等待用户明确指示**

## 六、中文显示规则

### 1. 面向网页/用户界面
- 所有显示给用户的文本必须使用中文
- 包括按钮文字、标签、提示信息、标题等
- 包括表格列名、表单字段标签

### 2. 导出/下载功能
- 文件名必须使用中文
- 导出的数据字段名必须使用中文
- Excel/Word/PDF 中的表头必须使用中文
- 示例：`职工退休呈报表_2025年.xlsx`

### 3. 数据传递
- 从后端传递到前端的数据，字段名使用中文
- API 返回的 JSON 中，key 使用中文
- 示例：`{"姓名": "张三", "出生日期": "1965-06-07"}`

### 4. 日期格式
- 显示格式：`YYYY年M月D日`
- 示例：`2025年8月7日`

### 5. 语言设置
- Element Plus 组件必须使用中文语言包
- 日期选择器、分页等组件显示中文

## 七、重要提醒

### 1. 查询现有表
在开发任何功能之前，必须先查询数据库中的现有表：
```sql
SELECT table_name 
FROM information_schema.tables 
WHERE table_schema = 'public' 
AND table_type = 'BASE TABLE'
ORDER BY table_name;
```

### 2. 查询现有字段
在使用任何表之前，必须先查询表的现有字段：
```sql
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = '表名'
ORDER BY ordinal_position;
```

### 3. 使用现有资源
- 只使用用户已经创建好的表
- 只使用现有表的现有字段
- 只使用用户已经创建好的菜单
- 只使用用户已经创建好的模块

---

## 八、模板管理设计思路（严格遵守）

### 1. 页面布局
```
┌─────────────────────────────────────────────────┐
│  模板管理                                        │
├─────────────────────────────────────────────────┤
│  [导入模板] [数据填报] [导出模板] [模板备份]      │
├─────────────────────────────────────────────────┤
│                                                  │
│  （当前标签页内容）                               │
│                                                  │
└─────────────────────────────────────────────────┘
```

### 2. 四个标签页（严格遵守）
1. **导入模板** - 导入Excel模板、预览模板、模板列表管理
2. **数据填报** - 选择模板、选择统计类型、字段映射、填报数据
3. **导出模板** - 导出Excel/PDF格式、选择导出位置
4. **模板备份** - 自动备份、审批备份、备份记录管理

### 3. 数据填报流程
```
步骤1：选择模板
步骤2：选择统计口径（标签选择）
步骤3：选择统计类型（单位/个人）
步骤4：字段映射与数据统计
步骤5：预览与确认
```

### 4. 统计类型
- **单位统计**：选择学校（从学校信息表）
- **个人统计**：选择教师（从教师基础信息表）

### 5. 字段映射
```
模板字段 -> 数据源表 -> 目标字段 -> 统计方式
```

### 6. 开发优先级
- ✅ 第一阶段：模板导入、模板预览、模板列表管理
- 🔄 第二阶段：数据填报基础功能、Excel导出
- 📋 第三阶段：字段映射配置、统计功能、PDF导出

**重要提醒：开发任何功能前，必须先查看此设计思路！**
