模板管理中心：

四大主要功能：导入模板、数据填报、导出模板，模板备份。这四个主要功能，如何设计：是在一个网页中，还是分四个（标签）网页中？

1.导入功能：在目前的基础上，是否增加WORD格式导入、PDF格式导入、数据库格式导入

二、数据填报

## 一、页面布局设计建议
### 方案对比
方案 优点 缺点 适用场景 单页面（步骤条） 流程清晰，一目了然 功能复杂时页面过长 简单的线性流程 标签页（推荐） 功能模块清晰，可独立操作 需要切换标签 多功能模块，相对独立 独立页面 各功能完全独立 导航复杂，用户体验不连贯 功能完全独立，无关联

### 我的建议：标签页方案
```

## 六、数据库设计建议
### 6.1 核心表结构
```
-- 模板主表
CREATE TABLE templates (
    template_id VARCHAR(50) PRIMARY KEY,
    template_name VARCHAR(200) NOT NULL,
    template_type VARCHAR(20), -- Excel/Word/PDF
    file_path VARCHAR(500),
    metadata_path VARCHAR(500),
    tags TEXT[], -- 标签数组
    status VARCHAR(20) DEFAULT 'active',
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    created_by VARCHAR(100)
);

-- 模板字段映射配置表
CREATE TABLE template_field_mappings (
    mapping_id SERIAL PRIMARY KEY,
    template_id VARCHAR(50),
    field_name VARCHAR(100), -- 模板字段名
    field_position VARCHAR(20), -- 坐标：C3, D5等
    source_table VARCHAR(100), -- 数据源表
    source_field VARCHAR(100), -- 目标字段
    stat_type VARCHAR(50), -- 统计方式
    stat_formula TEXT, -- 自定义公式
    created_at TIMESTAMP,
    FOREIGN KEY (template_id) REFERENCES templates
    (template_id)
);

-- 填报记录表
CREATE TABLE fill_records (
    record_id SERIAL PRIMARY KEY,
    template_id VARCHAR(50),
    fill_type VARCHAR(20), -- unit/personal
    fill_target VARCHAR(200), -- 单位名称或个人姓名
    fill_date TIMESTAMP,
    filled_by VARCHAR(100),
    status VARCHAR(20), -- draft/submitted/
    approved
    file_path VARCHAR(500),
    created_at TIMESTAMP,
    FOREIGN KEY (template_id) REFERENCES templates
    (template_id)
);

-- 备份记录表
CREATE TABLE backup_records (
    backup_id SERIAL PRIMARY KEY,
    record_id INTEGER,
    backup_type VARCHAR(50), -- auto_fill/
    approval/upload
    backup_format VARCHAR(20), -- Excel/PDF
    file_path VARCHAR(500),
    file_size INTEGER,
    created_at TIMESTAMP,
    FOREIGN KEY (record_id) REFERENCES 
    fill_records(record_id)
);
```
