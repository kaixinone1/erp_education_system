# 项目规则

## ⚠️ 宪法级规则（最高优先级，绝对不可违反）

### 🔴 强制性规则：面向用户的一切显示必须使用中文

**这是最高优先级的规则，每次编写代码前必须先检查此规则！**

#### 1. 面向用户的表名、字段名、文件名必须使用中文
- ✅ **前端界面显示**：所有表名、字段名必须使用中文
- ✅ **API返回数据**：JSON中的key必须使用中文
- ✅ **导出文件名**：Excel、PDF、Word文件名必须使用中文
- ✅ **数据库查询结果**：返回给前端的字段名必须使用中文

#### 2. 具体要求
- **前端界面**：按钮、标签、表格列名、表单字段、提示信息等所有文本必须使用中文
- **后端API**：返回的JSON数据中，所有key必须使用中文（如 `{"姓名": "张三"}`）
- **导出文件**：文件名格式必须为中文（如 `绩效工资审批表_2026年5月.xlsx`）
- **日期格式**：显示格式必须为 `YYYY年M月D日`（如 `2026年5月10日`）

#### 3. 违反后果
- **立即停止编写代码**
- **检查所有已编写的代码**
- **修改所有违反此规则的地方**
- **向用户道歉并说明修改情况**

#### 4. 检查清单（每次编写代码前必须检查）
- [ ] 前端界面所有文本是否使用中文？
- [ ] API返回的JSON字段名是否使用中文？
- [ ] 导出文件名是否使用中文？
- [ ] 日期格式是否使用中文格式？
- [ ] 表格列名是否使用中文？

## 绝对禁止硬编码

### 1. 禁止硬编码任何数据
- 包括默认值、测试数据、示例数据
- 包括字符串、数字、布尔值等任何类型的数据

### 2. 禁止硬编码任何字段值
- 如 `'退休原因': '正常退休'`
- 如 `'岗位': '教学岗位'`
- 如 `'职务': '教师'`

### 3. 禁止硬编码任何数字
- 如仪表盘统计数字 `23`、`5`、`18`
- 如分页大小、默认值等

### 4. 禁止硬编码任何字符串
- 如状态值 `'pending'`、`'completed'`
- 如类型值、分类值等

## 绝对禁止私自修改用户要求

### 1. 禁止私自修改用户的指示
- 禁止改变用户的原意
- 禁止添加用户没有要求的功能
- 禁止删除用户要求保留的内容

### 2. 禁止私自解释用户要求
- 必须按照用户的字面意思执行
- 有疑问时必须询问，不能自行判断

## 绝对禁止私自添加

### 1. 禁止私自添加字段
- 禁止在现有表中添加新字段
- 禁止使用 `ALTER TABLE ADD COLUMN`

### 2. 禁止私自添加表
- 禁止创建新表
- 禁止使用 `CREATE TABLE`

### 3. 禁止私自添加表名
- 禁止创建新的表名映射
- 禁止添加新的表名配置

### 4. 禁止私自添加数据
- 禁止写入测试数据
- 禁止写入示例数据
- 禁止创建测试脚本
- 禁止使用 `INSERT` 写入硬编码数据

## 正确做法

1. **从数据库查询真实数据**
   - 使用 `SELECT` 查询现有表
   - 使用现有字段，不添加新字段

2. **如果没有数据，保持为空**
   - 使用 `None` 或空字符串 `''`
   - 绝不使用默认值填充

3. **如果数据不存在，报错或提示用户**
   - 不假设数据存在
   - 不自动创建数据

4. **如果需要添加任何东西，必须询问用户**
   - 停止工作
   - 向用户说明需求
   - 等待用户明确许可

## 开发测试规则

### 🔴 强制性规则：必须打开内置浏览器测试

**每次修改前端代码后，必须打开内置浏览器进行实际测试！**

#### 1. 测试要求
- ✅ **修改前端代码后**：必须打开浏览器测试
- ✅ **修改API接口后**：必须测试API调用
- ✅ **修改样式后**：必须查看实际效果
- ✅ **添加新功能后**：必须完整测试功能流程

#### 2. 测试流程
1. 修改代码
2. 刷新浏览器页面
3. 实际操作测试功能
4. 确认功能正常工作
5. 才能告知用户完成

#### 3. 禁止行为
- ❌ 只测试后端代码，不测试前端
- ❌ 只看代码逻辑，不实际运行
- ❌ 假设代码正确，不验证效果
- ❌ 提交代码前不测试

#### 4. 违反后果
- 用户发现错误时，必须立即修复
- 不得找借口推脱责任
- 必须重新测试确认修复

## 中文显示规则

### 1. 面向网页/用户界面
- 所有显示给用户的文本必须使用中文
- 包括按钮文字、标签、提示信息、标题等
- 包括表格列名、表单字段标签

### 2. 导出/下载功能
- 文件名必须使用中文
- 导出的数据字段名必须使用中文
- Excel/Word/PDF 中的表头必须使用中文
- 示例：`职工退休呈报表_2025年.xlsx`

### 3. 数据传递
- 从后端传递到前端的数据，字段名使用中文
- API 返回的 JSON 中，key 使用中文
- 示例：`{"姓名": "张三", "出生日期": "1965-06-07"}`

### 4. 日期格式
- 显示格式：`YYYY年M月D日`
- 示例：`2025年8月7日`

### 5. 语言设置
- Element Plus 组件必须使用中文语言包
- 日期选择器、分页等组件显示中文
