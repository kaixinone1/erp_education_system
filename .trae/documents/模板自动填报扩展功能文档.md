# 模板自动填报系统扩展功能文档

## 扩展功能概述

模板自动填报系统提供丰富的扩展功能，包括：
- 批量生成报表
- 历史记录和统计
- 配置导入导出
- 自定义转换函数
- 数据验证

---

## 一、批量生成功能

### 功能说明
支持一次生成多个报表，适用于需要按不同条件生成多个报表的场景。

### API端点
```
POST /api/auto-fill/batch-generate
```

### 请求示例
```json
{
  "config_name": "退休呈报表",
  "filter_groups": [
    {
      "employment_status": "退休",
      "unit": "第一中学"
    },
    {
      "employment_status": "退休",
      "unit": "第二中学"
    },
    {
      "employment_status": "退休",
      "unit": "第三中学"
    }
  ],
  "naming_pattern": "{config_name}_{filter_value}_{timestamp}"
}
```

### 响应示例
```json
{
  "success": true,
  "message": "批量生成完成，成功 3 个，失败 0 个",
  "total": 3,
  "success_count": 3,
  "failed_count": 0,
  "results": [
    {
      "index": 1,
      "filters": {"employment_status": "退休", "unit": "第一中学"},
      "success": true,
      "output_file": "退休呈报表_退休_第一中学_20240510_143025.xlsx",
      "data_count": 5
    },
    {
      "index": 2,
      "filters": {"employment_status": "退休", "unit": "第二中学"},
      "success": true,
      "output_file": "退休呈报表_退休_第二中学_20240510_143026.xlsx",
      "data_count": 3
    },
    {
      "index": 3,
      "filters": {"employment_status": "退休", "unit": "第三中学"},
      "success": true,
      "output_file": "退休呈报表_退休_第三中学_20240510_143027.xlsx",
      "data_count": 4
    }
  ]
}
```

### 使用场景
- 按单位生成各自的报表
- 按月份生成月度报表
- 按类型生成分类报表

## 二、历史记录功能

### 功能说明
记录每次报表生成的历史信息，包括配置、筛选条件、统计数据、执行状态等。

### 2.1 获取历史记录

**API端点：**
```
GET /api/auto-fill/history?limit=100&config_name=退休呈报表
```

**参数：**
- `limit`: 限制数量（默认100）
- `config_name`: 配置名称（可选，用于过滤）

**响应示例：**
```json
{
  "success": true,
  "history": [
    {
      "id": 1,
      "config_name": "退休呈报表",
      "template_file": "退休呈报表.xlsx",
      "output_file": "退休呈报表_20240510_143025.xlsx",
      "data_count": 10,
      "filters": {"employment_status": "退休"},
      "statistics": {"退休人数": 10, "平均年龄": 60.5},
      "consistency_check": true,
      "execution_time": 2.5,
      "status": "success",
      "error_message": "",
      "created_at": "2024-05-10 14:30:25",
      "created_by": "system"
    }
  ],
  "count": 1
}
```

### 2.2 获取统计信息

**API端点：**
```
GET /api/auto-fill/statistics?config_name=退休呈报表
```

**响应示例：**
```json
{
  "success": true,
  "statistics": {
    "total_count": 100,
    "success_count": 95,
    "failed_count": 5,
    "avg_execution_time": 2.3,
    "total_data_count": 1000
  }
}
```

**API端点：**

      "calculations": [...]

  "config_name": "退休呈报表",

{

## 四、自定义转换函数功能

### 功能说明
允许用户注册自定义转换函数，扩展数据处理能力。

### 4.1 注册自定义函数

**API端点：**
```
POST /api/auto-fill/custom-functions
```

**请求示例：**
```json
{
  "function_name": "calculate_work_years",
  "function_code": "def calculate_work_years(join_date):\n    from datetime import datetime\n    if not join_date:\n        return 0\n    return datetime.now().year - join_date.year",
  "description": "计算工作年限"
}
```

**响应示例：**
```json
{
  "success": true,
  "message": "自定义函数注册成功",
  "function_name": "calculate_work_years"
}
```

### 4.2 获取所有自定义函数

**API端点：**
```
GET /api/auto-fill/custom-functions
```

**响应示例：**
```json
{
  "success": true,
  "functions": [
    {
      "name": "calculate_work_years",
      "code": "def calculate_work_years(join_date):\n    ...",
      "description": "计算工作年限",
      "created_at": "2024-05-10 14:30:25"
    }
  ],
  "count": 1
}
```

### 使用示例
注册后，可在配置中使用：
```json
{
  "template_field": "工作年限",
  "source_field": "join_work_date",
  "target_field": "工作年限",
  "transform": "calculate_work_years"
}
```

## 五、数据验证功能

### 功能说明
在填报前验证数据，检查数据完整性和有效性。

### API端点
```
POST /api/auto-fill/validate-data
```

### 请求示例
```json
{
  "config_name": "退休呈报表",
  "filters": {
    "employment_status": "退休"
  }
}
```

### 响应示例
```json
{
  "success": true,
  "has_errors": false,
  "data_count": 10,
  "validations": [
    {
      "field": "姓名",
      "status": "ok",
      "message": "字段 name 数据完整"
    },
    {
      "field": "身份证号",
      "status": "ok",
      "message": "字段 id_card 数据完整"
    },
    {
      "field": "出生日期",
      "status": "warning",
      "message": "字段 birth_date 有 2/10 条空值"
    }
  ],
  "can_proceed": true
}
```

### 验证状态
- `ok`: 数据完整
- `warning`: 部分数据缺失
- `error`: 字段不存在或全部为空

## 六、完整工作流程示例

### 场景：批量生成各单位退休报表

```python
import requests

base_url = 'http://127.0.0.1:8000/api/auto-fill'

# 1. 获取所有单位
response = requests.get(f'{base_url}/data-sources/dict_unit_dictionary')
units = response.json()['table_info']['fields']['unit']

# 2. 准备批量生成配置
batch_config = {
    'config_name': '退休呈报表',
    'filter_groups': [
        {'employment_status': '退休', 'unit': unit}
        for unit in units
    ],
    'naming_pattern': '退休呈报表_{filter_value}_{timestamp}'
}

# 3. 执行批量生成
response = requests.post(f'{base_url}/batch-generate', json=batch_config)
result = response.json()

print(f"批量生成完成：成功 {result['success_count']} 个，失败 {result['failed_count']} 个")

# 4. 查看历史记录
response = requests.get(f'{base_url}/history?limit=10')
history = response.json()
print(f"最近生成记录：{history['count']} 条")

# 5. 查看统计信息
response = requests.get(f'{base_url}/statistics')
stats = response.json()['statistics']
print(f"总生成次数：{stats['total_count']}")
print(f"成功率：{stats['success_count']/stats['total_count']*100:.2f}%")
```

## 八、数据库表结构

### auto_fill_history 表
```sql
CREATE TABLE auto_fill_history (
    id SERIAL PRIMARY KEY,
    config_name VARCHAR(255) NOT NULL,
    template_file VARCHAR(500),
    output_file VARCHAR(500),
    data_count INTEGER,
    filters JSONB,
    statistics JSONB,
    consistency_check BOOLEAN,
    execution_time FLOAT,
    status VARCHAR(50),
    error_message TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    created_by VARCHAR(100)
);
```
