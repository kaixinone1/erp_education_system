# 通用模板自动填报系统架构设计

## 一、系统架构总览

### 1.1 核心理念
**一个引擎，处理所有模板** - 不为每个模板单独开发，而是建立通用的处理引擎。

### 1.2 系统组成
```

│                    通用模板自动填报系统                        │
```

## 二、核心引擎设计

### 2.1 模板导入引擎（Template Import Engine）

**功能**：将任意Excel模板转换为JSON配置文件

**输入**：Excel文件（.xlsx）

**输出**：JSON配置文件，包含：
```json
{
  "模板ID": "retirement_form",
  "模板名称": "职工退休呈报表",
  "原始文件": "retirement_template.xlsx",
  "页面设置": {
    "纸张大小": "A4",
    "方向": "纵向",
    "边距": {"上": 72, "右": 54, "下": 72, "左": 54}
  },
  "列宽": [84, 100, 100, 100, 75],
  "行数据": [
    {
      "行号": 1,
      "高度": 27.0,
      "单元格": [
        {
          "列号": 1,
          "文本": "职工退休呈报表",
          "跨行": 1,
          "跨列": 6,
          "样式": "font-size:16pt;font-weight:bold;text-align:center",
          "对齐": "center"
        }
      ]
    }
  ],
  "字段映射": {
    "姓名": {"行": 3, "列": 2, "数据源": "teacher_basic_info.name"},
    "性别": {"行": 3, "列": 4, "数据源": "teacher_basic_info.gender"},
    "出生日期": {"行": 4, "列": 2, "数据源": "teacher_basic_info.birth_date"}
  }
}
```

**实现代码**：
```python
def import_template(excel_path):
    """导入Excel模板，生成JSON配置"""
    wb = load_workbook(excel_path)
    ws = wb.active
    
    config = {
        "页面设置": extract_page_setup(ws),
        "列宽": extract_column_widths(ws),
        "行数据": extract_rows_data(ws),
        "合并单元格": extract_merged_cells(ws)
    }
    
    return config
```

### 2.2 模板预览引擎（Template Preview Engine）

**功能**：根据JSON配置，100%复制原始模板外观

**输入**：JSON配置文件

**输出**：HTML表格（完全复制原始模板）

**核心算法**：
```python
def preview_template(config):
    """预览模板 - 100%复制"""
    html = '<table style="border-collapse: collapse;">'
    
    # 应用列宽
    html += '<colgroup>'
    for width in config['列宽']:
        html += f'<col style="width: {width}pt;">'
    html += '</colgroup>'
    
    # 渲染每一行
    for row in config['行数据']:
        html += f'<tr style="height: {row["高度"]}px;">'
        
        # 渲染每个单元格
        for cell in row['单元格']:
            style = build_cell_style(cell)
            rowspan = f' rowspan="{cell["跨行"]}"' if cell["跨行"] > 1 else ''
            colspan = f' colspan="{cell["跨列"]}"' if cell["跨列"] > 1 else ''
            
            html += f'<td style="{style}"{rowspan}{colspan}>{cell["文本"]}</td>'
        
        html += '</tr>'
    
    html += '</table>'
    return html
```

### 2.3 数据填报引擎（Data Fill Engine）

**功能**：根据字段映射配置，自动从数据库查询数据并填充

**输入**：
- JSON配置文件（包含字段映射）
- 查询条件（如：职工ID、年月等）

**输出**：填充后的JSON数据

**核心算法**：
```python
def fill_template_data(config, query_params):
    """自动填报数据"""
    filled_data = copy.deepcopy(config)
    
    # 遍历所有字段映射
    for field_name, mapping in config['字段映射'].items():
        # 解析数据源：表名.字段名
        table, column = mapping['数据源'].split('.')
        
        # 从数据库查询
        value = query_from_database(table, column, query_params)
        
        # 填充到对应单元格
        row_idx = mapping['行'] - 1
        col_idx = mapping['列'] - 1
        filled_data['行数据'][row_idx]['单元格'][col_idx]['文本'] = value
    
    return filled_data
```

### 2.4 数据导出引擎（Data Export Engine）

**功能**：将填充后的数据导出为Excel文件，保持原始格式

**输入**：填充后的JSON数据

**输出**：Excel文件（.xlsx）

**核心算法**：
```python
def export_to_excel(filled_data, output_path):
    """导出为Excel，保持格式"""
    wb = Workbook()
    ws = wb.active
    
    # 应用页面设置
    apply_page_setup(ws, filled_data['页面设置'])
    
    # 应用列宽
    for col_idx, width in enumerate(filled_data['列宽'], 1):
        ws.column_dimensions[get_column_letter(col_idx)].width = width
    
    # 写入数据
    for row in filled_data['行数据']:
        for cell in row['单元格']:
            ws_cell = ws.cell(row['行号'], cell['列号'])
            ws_cell.value = cell['文本']
            apply_cell_style(ws_cell, cell)
    
    # 处理合并单元格
    for merged in filled_data['合并单元格']:
        ws.merge_cells(f"{merged['起始']}{merged['结束']}")
    
    wb.save(output_path)
```

## 三、数据库设计

### 3.1 模板配置表
```sql
CREATE TABLE template_configs (
    id SERIAL PRIMARY KEY,
    模板ID VARCHAR(50) UNIQUE NOT NULL,
    模板名称 VARCHAR(100) NOT NULL,
    模板类型 VARCHAR(50),  -- '退休呈报表', '绩效工资审批表', '调令'等
    配置JSON JSONB NOT NULL,
    原始文件路径 VARCHAR(255),
    创建时间 TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    更新时间 TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 3.2 字段映射表
```sql
CREATE TABLE template_field_mappings (
    id SERIAL PRIMARY KEY,
    模板ID VARCHAR(50) REFERENCES template_configs(模板ID),
    字段名称 VARCHAR(100) NOT NULL,
    行号 INTEGER NOT NULL,
    列号 INTEGER NOT NULL,
    数据源表 VARCHAR(100),
    数据源字段 VARCHAR(100),
    转换函数 VARCHAR(100),  -- 如：'format_date', 'format_currency'
    默认值 VARCHAR(255)
);
```

### 3.3 填报记录表
```sql
CREATE TABLE template_fill_records (
    id SERIAL PRIMARY KEY,
    模板ID VARCHAR(50) REFERENCES template_configs(模板ID),
    填报时间 TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    查询条件 JSONB,
    填报数据 JSONB,
    导出文件路径 VARCHAR(255),
    操作人 VARCHAR(100)
);
```

## 五、工作流程

### 5.1 新模板导入流程
```
1. 用户上传Excel模板文件
   ↓
2. 模板导入引擎解析Excel
   ↓
3. 自动生成JSON配置（列宽、行高、单元格样式）
   ↓
4. 保存到数据库（template_configs表）
   ↓
5. 用户配置字段映射（点击单元格，指定数据源）
   ↓
6. 保存字段映射到数据库（template_field_mappings表）
```

### 5.2 模板填报流程
```
1. 用户选择模板
   ↓
2. 用户输入查询条件（如：职工ID、年月）
   ↓
3. 数据填报引擎根据字段映射查询数据库
   ↓
4. 自动填充数据到模板
   ↓
5. 预览填充结果
   ↓
6. 用户确认后导出Excel
```

## 六、优势分析

### 6.1 相比单独开发每个模板
| 对比项 | 单独开发 | 通用系统 |
|--------|---------|---------|
| 新模板接入时间 | 2-3天 | 10分钟 |
| 代码维护量 | 每个模板独立维护 | 统一维护引擎 |
| 扩展性 | 需要新开发 | 只需配置 |
| 一致性 | 各模板风格不一 | 统一风格 |

### 6.2 关键优势
1. **零代码接入新模板**：只需导入Excel + 配置字段映射
2. **100%复制原始模板**：自动提取所有格式信息
3. **数据驱动**：从数据库查询真实数据，无硬编码
4. **可追溯**：所有填报记录保存到数据库
5. **批量处理**：支持批量填报、批量导出
