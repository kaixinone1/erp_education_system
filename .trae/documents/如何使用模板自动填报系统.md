## 二、测试页面功能

### 1. 配置管理
- 点击"加载配置"按钮
- 查看已有的配置列表
- 显示配置名称、模板名称、类型等信息

### 2. 数据源
- 点击"加载数据源"按钮
- 查看数据源表总数（110个）
- 查看所有类别

### 3. 自动填报
- 选择配置（如"退休呈报表"）
- 设置筛选条件（如 `{"employment_status": "退休"}`）
- 点击"预览数据"查看数据
- 点击"执行填报"生成报表
- 查看填报结果

### 4. 历史记录
- 点击"加载历史"按钮
- 查看最近的填报记录
- 显示配置名称、数据量、状态、时间

### 5. 统计信息
- 点击"加载统计"按钮
- 查看总生成次数、成功/失败次数
- 查看平均执行时间、总数据量

## 三、API接口使用

### 基础URL
```
http://127.0.0.1:8000/api/auto-fill
```

### 常用接口

#### 1. 获取配置列表
```bash
GET /configs
```

#### 2. 获取数据源表
```bash
GET /data-sources
```

#### 3. 执行自动填报
```bash
POST /execute
{
  "config_name": "退休呈报表",
  "filters": {"employment_status": "退休"}
}
```

#### 4. 预览填报数据
```bash
POST /preview-fill
{
  "config_name": "退休呈报表",
  "filters": {"employment_status": "退休"}
}
```

#### 5. 批量生成
```bash
POST /batch-generate
{
  "config_name": "退休呈报表",
  "filter_groups": [
    {"employment_status": "退休", "unit": "第一中学"},
    {"employment_status": "退休", "unit": "第二中学"}
  ]
}
```

#### 6. 获取历史记录
```bash
GET /history?limit=20
```

#### 7. 获取统计信息
```bash
GET /statistics
```

## 四、Python调用示例

```python
import requests

API_BASE = 'http://127.0.0.1:8000/api/auto-fill'

# 1. 获取配置列表
response = requests.get(f'{API_BASE}/configs')
configs = response.json()['configs']
print(f"配置数量: {len(configs)}")

# 2. 执行自动填报
response = requests.post(
    f'{API_BASE}/execute',
    json={
        'config_name': '退休呈报表',
        'filters': {'employment_status': '退休'}
    }
)

result = response.json()
if result['success']:
    print(f"生成文件: {result['output_file']}")
    print(f"数据量: {result['data_count']} 条")
    print(f"统计: {result['statistics']}")
else:
    print(f"失败: {result['message']}")

# 3. 批量生成
response = requests.post(
    f'{API_BASE}/batch-generate',
    json={
        'config_name': '退休呈报表',
        'filter_groups': [
            {'employment_status': '退休', 'unit': '第一中学'},
            {'employment_status': '退休', 'unit': '第二中学'}
        ]
    }
)

batch_result = response.json()
print(f"批量生成: 成功 {batch_result['success_count']} 个，失败 {batch_result['failed_count']} 个")

# 4. 查看历史记录
response = requests.get(f'{API_BASE}/history?limit=10')
history = response.json()['history']
print(f"历史记录: {len(history)} 条")

# 5. 查看统计信息
response = requests.get(f'{API_BASE}/statistics')
stats = response.json()['statistics']
print(f"总生成次数: {stats['total_count']}")
print(f"成功率: {stats['success_count']/stats['total_count']*100:.2f}%")
```

## 七、注意事项

### 1. 服务启动顺序
1. 先启动后端服务
2. 再启动前端服务
3. 确保数据库连接正常

### 2. 配置文件
- 配置文件位置：`backend/config/template_configs/`
- 已有配置：退休呈报表、绩效工资审批表

### 3. 模板文件
- 模板文件位置：`backend/templates/`
- 输出文件位置：`backend/output/`

### 4. 数据库
- 历史记录表：`auto_fill_history`
- 自动创建，无需手动操作
