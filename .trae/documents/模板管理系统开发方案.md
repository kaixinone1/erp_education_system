# 模板管理系统开发方案

## 一、需求分析

### 1.1 核心需求概述

根据业务讨论，模板管理系统需要实现以下核心功能：

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| REQ-001 | 模板导入100%复制功能：原模板 == 网页预览 == 填报数据后导出 | 高 |
| REQ-002 | 字段配置：智能分析模板字段，建立字段配置文档 | 高 |
| REQ-003 | 数据填报：根据字段映射自动从数据库各表获取数据（支持计数、求和等） | 高 |
| REQ-004 | 模板导出：保持格式一致性 | 高 |
| REQ-005 | 表名/字段名映射优化：确保翻译有意义，杜绝序号类无意义翻译 | 高 |
| REQ-006 | 零费用实现：不使用付费翻译API | 高 |

### 1.2 功能需求详细说明

#### 1.2.1 模板导入功能
- **高通用性**：保证每一个模板都能100%精准复制
- **元数据完整提取**：包括页面设置、列宽、行高、合并单元格、样式等
- **格式无损转换**：Excel → JSON配置 → HTML预览 → Excel导出，全程格式保持一致

#### 1.2.2 字段配置管理
- **智能字段识别**：自动分析模板中的数据字段
- **配置文件管理**：一个模板对应一个专用字段配置文件
- **数据源映射**：支持选择用户导入的表作为数据源

#### 1.2.3 数据填报功能
- **自动数据获取**：根据字段映射从数据库各表查询数据
- **计算支持**：支持计数(COUNT)、求和(SUM)等聚合运算
- **配置文件管理**：一个模板对应一个自动填报配置文件

#### 1.2.4 映射优化功能
- **无意义翻译检测**：自动识别 `field_1`、`tmp7im827sg` 等无意义翻译
- **高质量翻译**：基于规则库和词典的精准翻译
- **双向映射**：中文 ↔ 英文一一对应，一次配置终身使用

## 二、系统架构设计

### 2.1 四层架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        前端展示层                               │
│  Vue 3 + Element Plus + Luckysheet                             │
│  - 模板管理页面                                                 │
│  - 字段配置面板                                                 │
│  - 模板预览界面                                                 │
│  - 数据填报界面                                                 │
├─────────────────────────────────────────────────────────────────┤
│                        API服务层                                │
│  FastAPI + 路由控制器                                           │
│  - /api/templates - 模板管理API                                 │
│  - /api/field-config - 字段配置API                              │
│  - /api/data-fill - 数据填报API                                 │
│  - /api/mapping-optimizer - 映射优化API                         │
├─────────────────────────────────────────────────────────────────┤
│                        核心引擎层                                │
│  模板导入引擎 / 预览引擎 / 填报引擎 / 导出引擎                     │
│  - TemplateImportEngine - Excel→JSON转换                        │
│  - TemplatePreviewEngine - JSON→HTML渲染                        │
│  - DataFillEngine - 数据查询与填充                              │
│  - DataExportEngine - JSON→Excel导出                            │
│  - MappingOptimizer - 映射优化服务                              │
├─────────────────────────────────────────────────────────────────┤
│                        数据存储层                                │
│  PostgreSQL + JSON配置文件                                      │
│  - template_configs - 模板配置表                                │
│  - template_field_mappings - 字段映射表                          │
│  - field_mappings.json - 通用字段映射配置                        │
│  - 各业务数据表（教师基础信息、绩效工资等）                       │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 核心组件设计

#### 2.2.1 模板导入引擎 (TemplateImportEngine)
- **输入**：Excel文件 (.xlsx)
- **输出**：JSON配置文件
- **核心功能**：
  - 提取页面设置（纸张大小、方向、边距）
  - 提取列宽、行高
  - 提取单元格内容和样式
  - 提取合并单元格信息

#### 2.2.2 模板预览引擎 (TemplatePreviewEngine)
- **输入**：JSON配置文件
- **输出**：HTML表格（100%复制原始模板）
- **核心功能**：
  - 使用Luckysheet实现WYSWYG预览
  - 保持所有格式属性（字体、颜色、对齐等）
  - 支持单元格编辑

#### 2.2.3 数据填报引擎 (DataFillEngine)
- **输入**：JSON配置 + 查询条件
- **输出**：填充后的JSON数据
- **核心功能**：
  - 解析字段映射配置
  - 动态生成SQL查询
  - 支持聚合函数（COUNT、SUM等）
  - 数据格式转换

#### 2.2.4 映射优化服务 (MappingOptimizer)
- **核心功能**：
  - 智能检测无意义字段名
  - 规则库匹配翻译
  - 拼音转换备用方案
  - 映射质量验证

## 三、数据库设计

### 3.1 模板配置表 (template_configs)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| id | SERIAL | 主键 |
| template_id | VARCHAR(50) | 模板唯一标识 |
| template_name | VARCHAR(100) | 模板名称（中文） |
| template_type | VARCHAR(50) | 模板类型 |
| config_json | JSONB | JSON配置内容 |
| original_file_path | VARCHAR(255) | 原始文件路径 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

### 3.2 字段映射表 (template_field_mappings)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| id | SERIAL | 主键 |
| template_id | VARCHAR(50) | 关联模板ID |
| chinese_name | VARCHAR(100) | 中文字段名 |
| english_name | VARCHAR(100) | 英文字段名 |
| row_number | INTEGER | 行号 |
| column_number | INTEGER | 列号 |
| data_table | VARCHAR(100) | 数据源表名 |
| data_field | VARCHAR(100) | 数据源字段名 |
| transform_func | VARCHAR(100) | 转换函数 |
| default_value | VARCHAR(255) | 默认值 |
| mapping_confidence | FLOAT | 映射置信度 |

### 3.3 填报记录表 (template_fill_records)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| id | SERIAL | 主键 |
| template_id | VARCHAR(50) | 关联模板ID |
| fill_time | TIMESTAMP | 填报时间 |
| query_params | JSONB | 查询条件 |
| filled_data | JSONB | 填报数据 |
| export_file_path | VARCHAR(255) | 导出文件路径 |
| operator | VARCHAR(100) | 操作人 |

### 3.4 通用字段映射配置 (field_mappings.json)

```json
{
  "version": "1.0",
  "mappings": {
    "姓名": "name",
    "性别": "gender",
    "出生日期": "birth_date"
  },
  "reverse_mappings": {
    "name": "姓名",
    "gender": "性别",
    "birth_date": "出生日期"
  },
  "rules": {
    "field_name_rules": {
      "身份证号码": "id_card",
      "参加工作日期": "work_start_date"
    }
  }
}
```

## 四、API接口设计

### 4.1 模板管理API

| API路径 | 方法 | 功能描述 |
|---------|------|---------|
| /api/templates | GET | 获取模板列表 |
| /api/templates/{template_id} | GET | 获取单个模板详情 |
| /api/templates | POST | 导入新模板 |
| /api/templates/{template_id} | PUT | 更新模板配置 |
| /api/templates/{template_id} | DELETE | 删除模板 |

### 4.2 字段配置API

| API路径 | 方法 | 功能描述 |
|---------|------|---------|
| /api/field-config/{template_id} | GET | 获取模板字段配置 |
| /api/field-config/{template_id} | PUT | 更新字段配置 |
| /api/field-config/{template_id}/optimize | POST | 优化字段映射 |

### 4.3 数据填报API

| API路径 | 方法 | 功能描述 |
|---------|------|---------|
| /api/data-fill/{template_id} | POST | 执行数据填报 |
| /api/data-fill/{template_id}/preview | POST | 预览填报结果 |
| /api/data-fill/records | GET | 获取填报记录列表 |

### 4.4 映射优化API

| API路径 | 方法 | 功能描述 |
|---------|------|---------|
| /api/mapping-optimizer/optimize-table-name | POST | 优化表名 |
| /api/mapping-optimizer/optimize-field-names | POST | 批量优化字段名 |
| /api/mapping-optimizer/validate | POST | 验证映射质量 |
| /api/mapping-optimizer/suggestions | POST | 获取翻译建议 |
| /api/mapping-optimizer/pending-report | GET | 获取待处理字段报告 |

## 五、关键技术选型

### 5.1 前端技术栈

| 技术 | 版本 | 选型理由 |
|------|------|---------|
| Vue 3 | 3.x | 响应式框架，性能优秀 |
| Element Plus | 2.x | 中文组件库，符合项目规则 |
| Luckysheet | 3.x | 专业在线电子表格，100%格式还原 |
| TypeScript | 5.x | 类型安全，代码可维护 |

### 5.2 后端技术栈

| 技术 | 版本 | 选型理由 |
|------|------|---------|
| FastAPI | 0.100+ | 高性能API框架，自动文档生成 |
| PostgreSQL | 16+ | 稳定可靠，支持JSONB |
| OpenPyXL | 3.x | Excel读写，保留格式信息 |
| python-Levenshtein | 0.21+ | 字符串相似度匹配 |

### 5.3 零费用翻译方案

| 方案 | 说明 | 优先级 |
|------|------|--------|
| 规则库匹配 | 教育领域专用词汇映射 | 最高 |
| 本地词典 | 内置中文字典翻译 | 高 |
| 拼音转换 | pypinyin库转换 | 备用 |

## 六、安全与合规

### 6.1 数据安全
- 敏感数据加密存储
- API访问权限控制
- 操作日志记录

### 6.2 合规要求
- 符合项目规则：面向用户显示必须使用中文
- 禁止硬编码数据
- 零费用实现，不使用付费API
